## 全局布局

`AppShell.vue` 统一提供主导航、顶部状态栏、工作区标签、全局搜索、主题切换、服务状态和账户操作。`NcLayout.vue` 统一页面标题、说明文字和页面动作区。页面通过 `.app-shell--terminal` 切换终端工作台的深色高密度区域。

主题由同一套 token 派生：浅色模式用于设备管理和运行总览，深色模式用于夜间运维和终端工作台。表格、徽标、空状态、弹窗和进度条使用同一语义色，不因主题切换而改变业务含义。

## 页面重构范围

### 运行总览

第一行提供登记设备、采集任务、服务告警、系统资源和实例健康 KPI。第二行提供设备状态分布、最近诊断和实时趋势，第三行提供最近任务与资源采样。没有真实 RSSI/吞吐时间序列时显示明确空状态，不绘制模拟曲线；没有独立告警 API 时显示“暂无可用告警记录”。

### 设备管理

设备页面使用新的 `/api/system/devices` 分页接口，提供搜索、状态筛选、20/50/100 行分页、刷新、详情、登记入口和真实外部工具动作。页面明确区分登记数量、有效性、启用/禁用和最近真实会话状态。缺少字段使用 `—` 并显示数据质量问题，不拼接孤立冒号。

### 终端控制台

终端页面采用三栏工作台：左侧设备搜索与列表，中间连接配置与协议参数，右侧真实 xterm.js 标签/分屏/工具栏；底部保留会话历史、终端回放、任务记录和导出能力。终端服务无可用设备时保留完整工作台结构并显示真实空态，不自动连接设备、不复制参考图中的 Huawei 输出。

### 任务、工具、文件和设置

这些页面复用统一 shell、标题区、卡片、表格和状态语义，保留既有真实 API、权限检查、文件下载、ZIP 任务、Desktop Helper 和设置边界。本次重点是统一信息密度与交互外观，不通过装饰性按钮扩展没有后端支持的功能。

## 实施边界

- 后端仍为 .NET 10，前端仍为 Vue 3 + TypeScript + Element Plus + ECharts + xterm.js。
- 新增设备库存查询 DTO 和最小映射层，没有重写 SQLite Schema、删除记录或复制旧前端。
- G1 Raw Recovery、Catalog、G2 H3C SSH、终端录制/回放、认证/CSRF、PR-2 文件管理和 ZIP 有界队列未被前端视觉重构绕过。
- 浏览器验收使用隔离数据根 `D:\NetConsoleNext-UIData`，不访问或修改 `D:\NetConsoleData`、`D:\NetConsoleData-dev`。
