# 功能迁移计划

1. P0：设备资产、真实连接、任务详情和无线 AC/AP 运行态；保持 Site scope、稳定 ID、Raw/Facts/Current 和审计合同。
2. P1：LLDP/拓扑资产工作台、网络诊断扩展、文件与报告导出、配置差异和恢复前置门禁。
3. P1：智能配置模板、变量、校验、dry-run 和批量任务；任何写入都必须有权限、预览、确认和回滚证据。
4. P2：轨道只读业务和跨机器部署；安装、TLS、升级/回滚在目标机可用前保持外部阻断。

每个迁移项必须同时具备源码映射、API 契约、状态矩阵、定向测试和 UI 证据。旧版行为可修正，但差异必须写入本矩阵和验收报告。
