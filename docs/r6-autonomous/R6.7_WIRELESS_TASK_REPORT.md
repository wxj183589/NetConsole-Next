# R6.7 wireless tasks

Status: **PARTIAL**. The UI supports Domain and optional AC selection, task history, detail, cancellation and ZIP download. The service limits history to the creator and rechecks current access to every target on detail and export. Service contract tests include revoked target access: history hides the task and detail/export reject it. HTTP Site claims revocation end-to-end remains NOT_TESTED.

ZIP contains task summary, AC execution results, an explicitly `NOT_PUBLISHED` observation placeholder, and a SHA-256 manifest. It excludes credentials and connection profiles. AP observations, parser summary, complete failure details, failed-target retry and real task publication remain incomplete. The exported ZIP is a summary, not a complete wireless result.

Real read-only probe evidence identified one AP from each AC, with R/M and R/B; those probe results have not been published through the wireless task as persistent AP resources or observations. See the device report.
