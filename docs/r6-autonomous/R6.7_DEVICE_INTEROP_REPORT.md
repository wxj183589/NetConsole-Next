outcomes and structured data. Command transport success is not treated as
parser success.

`display redundancy` unrecognized on both ACs. No supported HA switchover
command or device-level redundancy role was established. The AP's R/M and R/B
observations are not proof of a successful HA switchover; switchover and

version and interface collection remain BLOCKED. No device configuration was
changed by this probe. The legacy NetConsole data roots were not accessed.
